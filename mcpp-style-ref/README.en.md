# mcpp-style-ref

[简体中文](README.md) | English

Teach your Coding Agent the **Modern / Module C++ (C++23)** style: identifier naming, module and `.cppm` / `.cpp` organisation, `import std`, and everyday idioms (`auto`, brace initialisation, smart pointers, `string_view`, `optional` / `expected`, RAII)

Taken from the mcpp community's [mcpp-style-ref](https://github.com/mcpp-community/mcpp-style-ref) (commit `c9ddaf7`). The only changes: two relative links into the upstream repository are now absolute, and the frontmatter names the licence

## Install

```bash
npx skills add yspbwx2010/skills --skill mcpp-style-ref
```

or the Claude Code plugin marketplace:

```text
/plugin marketplace add yspbwx2010/skills
/plugin install mcpp-style-ref@yspbwx2010-skills
```

or copy `mcpp-style-ref/skills/mcpp-style-ref/` into your agent's skills directory (`~/.claude/skills/` for Claude Code)
